# Liquid Football Web Edition

A self-contained original browser football prototype inspired by arcade soccer and modern football-game controls. It uses procedural 3D assets generated by code, so the ZIP contains the game's source and does not depend on downloaded proprietary models or textures.

## Run it
Because the game uses JavaScript modules, open it through a local web server rather than `file://`.

### Python
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

### Node
```bash
npx serve .
```

## Controls
- WASD / arrow keys: move
- Shift: sprint
- J: pass
- K or Space: shoot
- L: tackle
- Q: switch player
- C: toggle follow / tactical camera
- Esc: pause
- Touchscreen: on-screen movement and action buttons

## What's included
- 3D pitch, goals, markings, generated stadium and crowd
- 22 procedural player models in two kit colors
- Ball movement, gravity, bounces, possession, passes, shots, tackles and scoring
- Follow camera and tactical camera
- Scoreboard, match clock, minimap, stamina and mobile controls

## Current scope
This is a playable browser prototype, not a 1:1 reproduction of Super Liquid Soccer or EA SPORTS FC. It uses original generic teams and procedural models. Advanced animation capture, full licensed club rosters, commentary, tournament menus, goalkeeper AI, and console-grade character rigs are not included. Three.js is loaded from jsDelivr, so the first run requires internet access.
